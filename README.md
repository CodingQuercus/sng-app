# Sketch'N'Guess

A GPS-based multiplayer drawing and guessing game for iOS and Android, built with React Native, Node.js and Socket.io.

Originally developed as a group project during the course *Prototyputveckling för mobila applikationer (5TF036)* at Umeå University (Autumn 2024). The codebase has since been refactored and cleaned up for portfolio purposes.

**Server repository: [sketch-n-guess-server](https://github.com/CodingQuercus/sng-server.git)**

## Tech stack
- React Native (Expo)
- Node.js + Socket.io
- Expo Router

## To get started

1. Install dependencies
```bash
   npm install
```

2. Create a `.env` file in the root:
SERVER_URL=http://YOUR_IP:3002


3. Start the app
```bash
   npx expo start
```

In the output, you'll find options to open the app in a
- [development build](https://docs.expo.dev/develop/development-builds/introduction/)
- [Android emulator](https://docs.expo.dev/workflow/android-studio-emulator/)
- [iOS simulator](https://docs.expo.dev/workflow/ios-simulator/)
- [Expo Go](https://expo.dev/go)
